01 / The problem

A good-looking backtest can still lie.

Trading ideas often peek at tomorrow, ignore costs, lean on one lucky stretch of history, or never compare against random timing. Hindsight turns those failure modes into visible checks.

The engine's contract

verdict = evidence, not vibes

02 / The approach

Code checks what the AI translates.

The model only converts your words into a rule sheet. Validation rejects unsupported or unsafe assumptions, then the transparent engine runs the test and writes the readable explanation.

03 / Evidence

Every result comes with a reason to doubt it.

The live report compares your strategy with holding, costs, look-ahead, market regimes, and random traders.

04 / The method

How it works

The AI does the translation. Code does the checking, backtesting, and explanation. Read the full walkthrough in HOW-IT-WORKS.md.

  1. Describe the idea

    Use ordinary words, such as buying Apple after a five-day drop.

  2. Translate it into rules

    The model lists every assumption and refuses what the data cannot support.

  3. Run the backtest

    Signals fill on the next day's open, with costs charged on both sides.

  4. Interrogate the result

    Compare it with holding, regimes, look-ahead, and random traders.
